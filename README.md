# learning — Experiments & Notes

This repo is a personal learning space where I keep notes, small experiments, and lightweight demos while exploring new data engineering tools and patterns.

## Purpose
- Capture quick experiments and proofs-of-concept
- Save concise HOWTOs and code snippets that may become full features later
- Record lessons learned and references when studying new tools

## Typical contents
- short scripts and Jupyter notebooks
- notes/ and docs/ with markdown explanations
- small demo projects showing a single concept end-to-end

## How to use
1. Clone the repo

```bash
git clone https://github.com/VishnuVardhanReddy009/learning.git
cd learning
```

2. Open notebooks or run small scripts. Keep environments isolated with venv or Docker.

## Suggested structure
```
learning/
├── notebooks/       # short experiments
├── scripts/         # one-off scripts
├── notes/           # markdown notes & howtos
└── README.md
```

## Contributing / Notes
